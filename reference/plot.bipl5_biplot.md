# Plot a bipl5_biplot object

Initialises a plotly graph, populates it with the first available
mdsDisplay traces and annotations, then attaches the remaining
mdsDisplays and fit measures to the JavaScript event handler.

## Usage

``` r
# S3 method for class 'bipl5_biplot'
plot(x, y = NULL, ...)
```

## Arguments

- x:

  A `bipl5_biplot` object

- y:

  Ignored (for S3 consistency)

- ...:

  Additional arguments (ignored)

## Value

A plotly htmlwidget
