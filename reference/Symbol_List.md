# Retrieve all valid plotting symbols for the `plotly` library

Retrieve all valid plotting symbols for the `plotly` library

## Usage

``` r
Symbol_List()
```

## Value

A vector of all the valid plotting symbols used in the
[`plot_ly`](https://rdrr.io/pkg/plotly/man/plot_ly.html) library.
