# bipl5 default color scales

bipl5 default color scales

## Usage

``` r
colorpal(number = 16)
```

## Arguments

- number:

  Integer - number of distinct colors to return. Ranges from 1 to 16.

## Value

Character vector of default colors in `bipl5`. There are sixteen unique
colors defined.

## Examples

``` r
colorpal(number=7)
#> [1] "#396AB1" "#DA7C30" "#3E9651" "#CC2529" "#535154" "#6B4C9A" "#922428"
```
